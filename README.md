## Featured Projects:

1. **Expense Tracking App**
    * **Description:** A practical tool designed to help users take control of their finances. It allows users to input expense names, descriptions, categories, and total amounts. It features an authentication screen for signing in or signing up, along with data persistence for user inputs.
    * **Tech Stack:** Created using **Flutter** <br><br><br>

2. **LOLCode Interpreter**
    * **Description:** A custom-built interpreter for the LOLCode programming language. This project explores the fundamentals of lexical and syntactical analysis by turning meme-based syntax into executable logic. It supports standard LOLCode commands, variable declarations, and basic arithmetic operations.
    * **Tech Stack:** Written entirely in **Python**, with a GUI created using **Python Shiny**<br><br><br>

3. **Mood Tracking App**
    * **Description:** A mobile application that helps users track their emotional well-being over time. Users can input their identity, exercise activity, current emotion, emotional intensity, and the day's weather.
    * **Tech Stack:** Created using **Flutter** <br><br><br>

4. **Silly Pedestrian**
    * **Description:** A simple local 1v1 2D game played on a single computer where two players must avoid incoming pedestrians. Each player has three lives; if a player loses all their lives, the opponent wins. If both players survive the two-minute time limit, they both win.
    * **Tech Stack:** Built using **Java** and the **JavaFX** library for rendering 2D graphics and managing the game loop.<br><br><br>

5. **Tagabook-It**
    * **Description:** A web application that facilitates direct transactions between sellers and customers. It features distinct interfaces for two user types: regular users and admins. The administrative dashboard manages product catalogs, tracks crop and poultry inventory, and generates weekly or annual sales reports. Customers can browse sorted inventories, manage dynamic shopping carts, and place Cash-on-Delivery orders.
    * **Tech Stack:** (**Frontend**)React.js, Tailwind CSS <br><br><br>

6. **Tekknoblade**
    * **Description:** A local 1v1 2D sword-fighting duel played on a single computer. It features simultaneous player movement on the horizontal axis and interaction through player-controlled attacks. It also utilizes collision detection to allow players to deal damage to one another.
    * **Tech Stack:** Built using **Java** and the **JavaFX** library for rendering 2D graphics and managing the game loop. <br><br><br>

7. **WeTravel**
    * **Description:** A travel app that organizes planning activities like itineraries and agendas. Users can input travel plan names, dates, and locations using an integrated map. It features modules for flight details, accommodations, checklists, and interest-based matchmaking. A profile page allows users to set their accounts to private, restricting others to seeing only their username and plan counts.
    * **Tech Stack:** Created using **Flutter**, **Firestore Cloud** for real-time database management, and **Firebase Authentication** for secure user login and data privacy.
  
8. **MILLI**
   * **Description:** Milli transforms the traditional, often confusing physical prescription into a streamlined digital experience. By combining automated transcription with a prioritized, high-glanceability tracking system, Milli ensures users never miss a dose. Beyond tracking, the app integrates a community forum where users can connect and share insights within a safe, moderated healthcare space.
   * **Prototype**
